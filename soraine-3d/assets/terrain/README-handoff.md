# 月表与火星地形 · Claude 前端交接

moon.glb 和 mars.glb 是两个独立静态网格。按目的地加载对应模型即可。两张 JPG 是同一视角的 Blender 渲染，方便比对几何和色调。

- 两块地形使用相同的局部坐标。GLB 为 Y 向上，水平覆盖约 64 × 40 米。原点位于地块内部，地面高度随位置变化。前端可沿用自身场景单位统一缩放。
- 模型使用顶点色和几何法线。加载器应保留文件自带的材质与 COLOR_0。用侧向平行光照出坑缘和岩层，环境光保留暗部。天空、灯光、相机由前端环境提供。
- Blender 预览的观察位置换算为 GLB 坐标是 (0, 3.8, 14)，看向 (0, 0.92, -5)。这是可选的起始视角。
- generate_surfaces.py 用于在 Blender 中重新生成模型。月球的 cr 列表控制主要坑中心和半径，火星的 mesas 列表控制岩台中心、水平半径和高度。随机种子固定。重新运行会覆盖输出目录中的同名 GLB。
- 两块地形均为低多边形场景概念模型，地貌尺寸与位置由程序设定。
